# 1.32.01 基线说明

本源码仓库于 2026-08-17 从桌面 `1.32.01` 交付目录整理得到。

纳入仓库的内容：

- `backend/src` Python 源码和测试；
- `backend/benchmarks` 验收场景定义；
- `dist` 中现有前端构建产物，保存为 `frontend-dist`；
- Windows 启停脚本和运行时清单模板；
- 从 1.32.01 随附 Python 运行时提取的依赖版本清单。

明确排除的内容：

- `artifacts`、测试截图、Trace 和历史报告；
- `data`、登录态、项目配置和模型 API 配置；
- `server.pid` 和服务日志；
- Python、Chromium、Docker 镜像等大体积运行时；
- Python 缓存和 pytest 缓存。

整理时只统一了源码版本标识，没有宣称修复业务逻辑，也没有把历史局部
通过记录转换成完整网站验收结果。

验证结果：

- 144 个 Python 文件均可被 AST 解析；
- 3 个 PowerShell 工具脚本均通过语法解析；
- 发布工具已完成隔离烟雾发布并通过 SHA256 校验；
- 后端测试为 243 通过，2 个本地 Playwright 夹具受 Codex 沙箱 EPERM
  限制未执行成功；
- 未执行 `192.168.31.218:7991` 或 Cesium 的真实端到端验收。
