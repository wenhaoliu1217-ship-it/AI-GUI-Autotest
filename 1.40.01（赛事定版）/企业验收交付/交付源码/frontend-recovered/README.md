# Recovered Frontend Sources

This directory contains versioned frontend source trees recovered from local
backups. A recovered tree must retain its original version and must not replace
`frontend-dist` until a separately reviewed migration and parity test passes.

Current recovery:

- `1.30.20`: complete React/Vite source baseline with lockfile and tests.
- `1.32.01`: exact source not found in the available release packages, ZIP
  archives, Git history or user-local project backups inspected on 2026-08-19.

See `../docs/frontend-source-status.md` for provenance and release gates.
