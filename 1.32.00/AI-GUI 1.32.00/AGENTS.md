# AI-GUI 1.32.00 开发规则

本目录是由冻结版 `1.31.00` 完整派生的独立 Web 产品工作区。

- 只能修改 `1.32.00`；不得回写、删除或覆盖 `1.31.00` 及更早版本。
- 普通模式的默认用户是假设完全不懂技术的人。默认流程必须是“输入网址 → AI 识别 → 登录接续（如需）→ 用聊天描述测试 → 看实时画面与普通中文结果”。
- 普通模式只显示“开始测试、测试记录、高级设置”；项目、环境、场景等技术层级必须保留在数据与高级设置中，不得删除。
- GAEALaViC、Cesium、京东只是内部重点适配对象，不得作为普通入口卡片或要求用户理解的分类；其他 Web 地址仍须允许接入。
- 京东完整验收仍保留全部 65 项固定检查，普通页面不得显示 J01～J65 技术编号。
- 默认审批模式为“请求批准”，每次新运行重置。三档审批不得削弱绝对安全规则。
- 产品可在支付环节交给用户本人接管，但项目验收不得发生真实付款。密码、验证码、生物识别、账号安全修改和非测试数据删除不得由 AI 完成。
- 模型接收 DOM 或截图必须逐网站授权。密钥、Cookie、验证码、设备标识、个人资料和交易标识不得进入明文证据。
- 固定计划、专业配置、报告、证据、回放、65 项验收等 1.31.00 能力必须继续保留；隐藏或合并入口不等于删除实现。
- 每批修改必须有相应测试，并同步源码、构建成品、版本状态和根接续说明。
