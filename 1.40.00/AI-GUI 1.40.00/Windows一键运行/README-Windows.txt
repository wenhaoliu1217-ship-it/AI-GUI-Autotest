京彩OPC AI 网站测试助手（1.40.00 持续工作台版）

一、启动

1. 完整解压交付包，不要只复制 BAT 文件。
2. 双击“启动AI-GUI.bat”或“Start-AI-GUI.bat”。
3. 一键包使用包内 Python、Playwright 和 Chromium，不联网安装依赖，也不要求 Docker Desktop。
4. 启动后默认打开 http://127.0.0.1:8080/，顶部应显示“真实执行服务已连接”。
5. 结束时双击“关闭AI-GUI.bat”或“Stop-AI-GUI.bat”。

二、推荐使用流程

1. 在工作台首条消息中发送网址；也可以直接写“网址 + 测试要求”。
2. 系统完成安全只读扫描后，会在同一工作台显示网站信息并保留已识别的要求。
3. 需要登录时，由用户在系统打开的独立 Edge 窗口中完成密码、验证码和账号确认。
4. 在工作台选择当前模型和审批级别后开始测试。
5. 执行画面、审批、结果和后续对话都留在同一工作台。

三、模型中心

1. 点击左侧“模型中心”。
2. 选择服务商，填写档案名称、模型名称和 API Key；Base URL、协议、价格等低频项位于“高级连接设置”。
3. 点击“验证并设为当前模型”，通过能力探针后即可在工作台快速切换。
4. 可以保存多个模型档案。切换模型不会打断正在进行的浏览器动作，新的运行使用当前模型。
5. API Key 使用 Windows DPAPI 按当前 Windows 用户加密保存；密钥不会返回浏览器，不会写入运行历史、日志、报告或交付导出。

四、安全边界

- 只对已获授权的网站执行测试。
- 扫描阶段只读取页面，不点击、不填写、不提交。
- 密码、验证码、生物识别、付款和账号安全修改始终由用户本人完成。
- 真实付款绝对禁止；危险写入动作仍受审批和项目安全规则限制。
- 模型接收脱敏 DOM 或截图必须按网站单独授权。

五、目录说明

- runtime/python/python.exe：随包 Python 3.12 与应用依赖。
- runtime/ms-playwright：与包内 Playwright 匹配的 Chromium 运行时。
- backend：本机后端与 Agent 执行能力。
- dist：1.40.00 前端构建成品。
- data/ai-profiles：模型档案元数据与 DPAPI 加密密钥文件。
- artifacts：真实运行截图、证据和报告。

本版本不会生成 Mock 成功结果。浏览器未实际完成的步骤不会显示为成功。
