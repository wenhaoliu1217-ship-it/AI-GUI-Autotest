# AI-GUI 1.40.00 开发规则

本目录由冻结的 `1.33.00` 完整派生，是独立的 Web 产品工作区。

- 只能修改 `1.40.00`；`../1.33.00`、`../1.32.00` 及更早版本均不得回写、删除或覆盖。
- 普通用户默认不懂编程和自动化测试。主流程必须是“AI 询问网址 → 识别网址与同条测试要求 → 如需则登录 → 同一工作台执行、显示结果并继续对话”。
- 普通导航显示“开始测试、测试记录、模型中心、高级设置”。模型中心承载高频模型切换；Base URL、协议、定价等技术项保留在其高级连接设置中。
- 允许保存多个模型档案；API Key 只可由 Windows DPAPI 按当前系统用户加密保存，不得返回浏览器、日志、报告或交付导出。
- 模型切换不打断正在进行的浏览器动作，新运行使用工作台当前选择的模型。
- Browser Use Cloud 只作为持续工作台和模型管理的体验参考，不得为了模仿而新增与本产品目标无关的功能。
- GAEALaViC、Cesium、京东只是内部重点适配对象，不得成为限制通用网站接入的专用入口。
- 京东完整验收仍保留全部 65 项固定检查，普通页面不得显示 J01～J65 技术编号。
- 默认审批模式为“请求批准”，每次新运行重置。密码、验证码、生物识别、账号安全修改、真实付款和非测试数据删除不得由 AI 完成。
- 模型接收 DOM 或截图必须逐网站授权。密钥、Cookie、验证码、设备标识、个人资料和交易标识不得进入明文证据。
- 固定计划、专业配置、报告、证据、回放、65 项验收及 1.33.00 的通用适配能力必须继续保留。
- 每批修改必须有相应测试，并同步源码、Windows 一键运行版、版本状态和接续说明。
