# AI-GUI 1.40.00 组员交付说明

## 交付定位

这是 AI-GUI 1.40.00 Windows 组员测试交付版。完整解压后即可启动，不需要安装 Python、Playwright、Chromium 或 Docker Desktop，也不会联网安装依赖。

本版本保留 1.33.00 的通用网站、Cesium、Agent、审批、证据、报告和京东 65 项验收能力，并新增持续工作台与多模型中心。

## 启动与停止

1. 完整解压 ZIP，路径尽量不要过深。
2. 双击 `双击启动AI测试.bat`；如果中文文件名显示异常，使用 `Start-AI-GUI.bat`。
3. 启动器会在 8080～8090 中选择空闲端口并打开 GUI。
4. 顶部显示“真实执行服务已连接”后再开始测试。
5. 结束时双击 `双击关闭AI测试.bat` 或 `Stop-AI-GUI.bat`。

## 首次配置模型

1. 打开左侧“模型中心”。
2. 选择服务商，填写档案名称、模型名称和组员自己的 API Key。
3. 协议、Base URL、价格等低频参数在“高级连接设置”中。
4. 点击“验证并设为当前模型”。能力探针通过后，工作台可快速切换模型。
5. API Key 使用 Windows DPAPI 按当前 Windows 用户加密保存；换电脑或换 Windows 用户后需要重新录入。

交付包不包含开发者的 API Key、模型档案、Cookie、登录态、运行历史或截图。

## 推荐测试流程

1. 在工作台直接输入网址，也可以一次输入“网址 + 测试要求”。
2. 系统先做安全只读扫描；需要登录时，由组员在打开的 Edge 窗口中完成密码和验证码。
3. 选择模型与审批模式后开始测试。
4. 网站画面、Agent 说明、审批、结果和继续对话都保留在同一工作台。
5. 建议依次验证：普通 DOM 网站、需要登录的网站、Cesium，以及至少两个模型档案的切换。

## 安全边界

- 只测试已获授权的网站和账号。
- 密码、验证码、生物识别、付款和账号安全修改必须由用户本人完成。
- 真实付款绝对禁止；危险写入仍受审批和项目安全规则约束。
- 模型接收脱敏 DOM 或截图必须按网站单独授权。

## 反馈问题时提供

- 测试要求和目标网址。
- GUI 显示的运行编号与错误提示。
- `artifacts` 中对应报告、截图或 trace。
- `server-stderr.log` 中与本次问题相关的片段。

不要发送 API Key、Cookie、密码或验证码。
