# AI-GUI 1.40.00 Windows 组员交付包封装清单

## 包含

- 1.40.00 生产前端 `dist`。
- 1.40.00 后端 `backend/src` 与必要 benchmark fixture。
- 内置 Python 3.12、Playwright 和 Chromium 运行时。
- Windows 启动/停止 BAT 与 PowerShell 脚本。
- 1.40.00 组员交付说明、使用验证说明和版本状态。

## 排除

- 源码开发目录、Node.js 依赖和 Docker 镜像。
- 历史 `artifacts`、项目数据、浏览器配置、登录态、Cookie、模型档案和 API Key。
- `.pytest-*`、`.pytest_cache`、测试源码、`__pycache__`、开发日志、PID 和临时文件。
- 上游开源仓库原件；产品所需适配代码已经包含在后端。

## 交付入口

- 顶层目录：`AI-GUI-1.40.00`
- 启动：`双击启动AI测试.bat` 或 `Start-AI-GUI.bat`
- 停止：`双击关闭AI测试.bat` 或 `Stop-AI-GUI.bat`
- 完整性：ZIP 同目录提供 SHA-256 文件。

首次启动会自动创建新的 `data`、`artifacts` 与日志，这些属于组员本机测试数据。
