# AI-GUI 1.40.00 版本更新与需求状态

更新时间：2026-08-06

## 总目标

在不改变“通用网站 GUI 自动测试助手”初衷和安全边界的前提下，选择性吸收 Browser Use Cloud 的高价值体验：持续单一工作台、任务结束后继续对话、多模型档案与快速切换。非必要的云平台、团队、计费和完整浏览器托管能力不照搬。

## 已完成

### 1. 独立版本基线

- 从冻结的 1.33.00 完整派生 `AI-GUI 1.40.00`。
- 1.33.00、1.32.00 及更早版本保持冻结，不反向修改。
- 前后端版本号和界面品牌更新为 1.40.00。

### 2. 持续工作台

- AI 首条消息先询问网址。
- 同一个输入框支持“只发网址”和“网址 + 测试要求”两种自然输入。
- 能从首条消息中提取 URL 和剩余自然语言目标；已提取目标自动带入测试准备阶段。
- 网站扫描、登录提示、测试要求、审批、执行画面和结果保持在同一工作台，不跳转到孤立结果页。
- 未配置模型时仍可完成安全只读扫描，并在开始 Agent 前明确引导到模型中心。

### 3. 多模型中心

- 支持 OpenAI、Kimi/Moonshot、DeepSeek、硅基流动和自定义兼容服务预设。
- 支持创建、编辑、删除、验证、设为当前模型和工作台快速切换。
- Provider、模型、协议、Base URL、价格和能力探针元数据均可独立保存。
- API Key 使用 Windows DPAPI 按当前系统用户加密，元数据与密钥文件分离；公共 API 不返回密钥。
- Agent 运行只提交 `profileId`，后端在本机解析实际密钥，避免密钥进入浏览器请求、历史和报告。
- 切换模型不会中断正在执行的浏览器动作；新的运行使用当前选中的模型。

### 4. 兼容性与安全

- 保留 1.33.00 的通用 Agent、固定计划、审批、证据、回放、报告、Cesium 适配和京东 65 项验收能力。
- 保留私网/回环地址默认阻断、逐网站 DOM/截图授权和危险动作审批。
- 模型档案数量上限为 20；Base URL 默认要求 HTTPS，本机 localhost/127.0.0.1 调试例外。

### 5. 已通过验证

- 前端 TypeScript/Lint。
- 前端 Vitest：44 项通过。
- 模型档案与 API 单元测试：42 项通过。
- Vite 生产构建通过。
- 真实界面验证：模型中心可打开；首条“网址 + 要求”可识别；example.com 扫描后目标被自动带入同一工作台。
