## 离线约束

- 启动器只使用 `runtime/python/python.exe`，不调用系统 Python，也不创建虚拟环境。
- `PLAYWRIGHT_BROWSERS_PATH` 固定指向包内 `runtime/ms-playwright`。
- 禁止在线运行 `pip install`、`playwright install` 和 `docker build`。
- Docker 中已有 `ai-gui-runner:1.30.00` 时直接复用；镜像不存在时只允许从包内 TAR 执行 `docker load`。
- Docker Desktop、WSL2 Linux Engine 与 Windows 虚拟化是系统级前提，不包含在 ZIP 内。
- Docker 不可用或交付文件不完整时明确失败，不降级为宿主进程执行测试。
- Uvicorn 子进程绑定启用 `KILL_ON_JOB_CLOSE` 的 Windows Job Object；关闭启动窗口时由系统回收本包服务进程树。
- `server.pid` 记录 PID、本包路径、便携 Python 路径和进程启动时间；正常退出自动清除。
- 启动前及 `stop.bat` 手动停止均严格核对同包 Python、启动时间和 Uvicorn 命令行，不按端口或进程名终止其他进程。
