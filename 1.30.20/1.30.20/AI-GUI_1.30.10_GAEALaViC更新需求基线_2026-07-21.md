# AI-GUI `1.30.10` GAEALaViC 接入更新需求基线

生成日期：2026-07-21

## 1. 范围原则

1. 指导书定义完整目标网站测试标准，GUI 必须按指导书补能力，不能根据当前实现反向删减网站测试范围。
2. `1.30.10` 只修改 `AI-GUI-Autotest\1.30.10`；`1.30.00` 已冻结，不再回写代码、测试、构建或文档。
3. `1.30.10` 负责 ER-07、GAEALaViC／首个企业测试网站适配、30 个基准场景×5 次重复和企业验收。ER-08 与第二个非 Cesium 业务网站验证归属 `1.30.20`。
4. 下列 P0／P1／P2 只表示实施顺序，不表示 P1／P2 可以从发布范围删除；`GAE-GUI-01～17` 均是 `1.30.10` 发布门槛。
5. Playwright 始终是唯一浏览器执行层。AI、视觉模型和 App Bridge 只能提供规划、观察或语义状态，不能绕过安全执行器直接操作目标系统。

## 2. `1.30.00` 已继承能力

以下能力直接继承，原则上不重复开发，但必须在 GAEALaViC 环境重新验收：

- 项目、环境、场景、允许域名、显式私网例外、Viewport、设备缩放、运行上限、普通变量和密钥引用。
- storageState 域名／Origin 校验、DPAPI 加密保存、交互式登录录制和敏感信息遮罩。
- Observation→Planner→单动作→再 Observation 的动态 Agent、三次无进展停止、locator／visual／app_bridge 模式记录。
- role、label、text、testId、CSS 定位，通用视觉点击／悬停／滚动／拖拽及动作后验证。
- Docker 隔离 Runner、域名与 WebSocket 网络边界、危险动作一次性确认、截图像素脱敏和运行工件生命周期。
- Generic／Cesium Bridge v1 五项契约、场景前后状态、截图、Trace 和七类 Canvas／Bridge Finding。
- Playwright TypeScript 生成、A～D 稳定性、stable／adaptive 回放、Finding 人工审核和离线报告。

这些能力“代码已存在”不等于目标站已通过；必须由本版本的场景和证据重新验证。

## 3. P0：接入与业务执行基础

### GAE-GUI-01：placeholder 与稳定属性原生定位

- Locator、Observation、Planner、人工计划编辑器和 Compiler 原生支持 `placeholder`、`data-test`、`data-qa` 等稳定属性。
- 多匹配时必须报告歧义或进入已声明作用域，禁止默认点击第一个。
- 验收：登录页租户、用户名、密码可仅凭语义定位完成正向和空值／错误密码负向用例；生成代码不退化为裸坐标。

### GAE-GUI-02：业务对象与容器作用域定位

- 支持 table row、card、dialog、tab panel、局部滚动容器和 canvas scope。
- 行内修改／预览／详情／复制／删除必须先锁定对象名或业务 ID，再在对象作用域内找动作。
- 支持模板列表滚动定位、表格列识别、分页和每页条数；删除前必须再次核对对象身份。
- 验收：同页存在多个同名操作按钮时可稳定操作指定 E2E 对象，错误对象零命中。

### GAE-GUI-03：测试文件仓库与受控上传

- 新增项目级测试文件仓库和 `upload` 动作，支持 JSON、ZIP、HGT、PNG／JPG、GIS、超大文件、错误扩展名和错误 schema。
- 测试文件只允许来自已登记 manifest；记录文件 ID、名称、大小、SHA-256、MIME／扩展名、合法性和预期结果。
- 单步证据记录上传请求／响应、生成业务对象 ID、失败错误和残留对象检查。
- 上传只允许专用测试环境和 E2E 命名对象；文件内容不进入模型上下文。
- 验收：S07／S08、S17～S21、S23／S24 可执行，合法与非法样例均有确定性结果和清理证据。

### GAE-GUI-04：受控下载与内容校验

- Runner 按需启用 Playwright download，并把文件限制在本次容器运行目录，禁止任意路径写入。
- 支持模型导出、仿真数据、评估数据、运行报告和训练结果。
- 证据包含文件名、响应头、大小、SHA-256、格式和内容结构校验；敏感下载执行保留与脱敏策略。
- 验收：S28 的仿真／评估下载均可关联运行 ID，文件存在、非空、哈希稳定且结构符合目标格式。

### GAE-GUI-05：异步状态机与 WebSocket 证据

- 新增业务状态等待／断言：允许状态、终态、失败态、轮询间隔、总超时和状态转换规则均由项目配置声明。
- 在现有 WebSocket 安全边界上增加事件采集、脱敏、业务 ID 关联、断连／重连记录；不能只做连接放行检查。
- 支持想定启动、仿真启动／运行中／停止／完成／失败，以及训练启动／训练中／停止／完成。
- 输出状态时间线，并区分启动失败、停止失败、环境超时和产品状态机异常。
- 验收：S26 有运行 ID、轮询或 WebSocket 证据、完整状态时间线和明确终态。

### GAE-GUI-06：业务测试数据生命周期与依赖图

- 对模型、环境资产、高程数据、想定、实例、DoE／运行和强化学习配置建立跨模块依赖图。
- 所有创建对象使用运行级唯一 `E2E_` 前缀并记录业务 ID；场景声明 setup、依赖、复用、rollback、cleanup 和失败后人工处理。
- 清理按依赖逆序执行，核对对象确实不可查；失败时生成 `cleanup-report.json`，不得用运行工件删除冒充业务对象清理。
- 验收：重复运行不污染固定租户，业务对象清理成功率 100%。

### GAE-GUI-08：动作级副作用策略矩阵

- 项目配置支持动作、对象类型、命名规则、环境、角色、前置状态、自动允许／需确认／条件允许／禁止、回滚和清理规则。
- 上传、创建、复制、启动仿真、停止仿真、下载、删除、批量删除分别执行指导书默认策略。
- 非 E2E 对象删除、支付／发布／邀请、容器重启和运维操作保持禁止；人工确认不能绕过绝对禁止项。
- 每次副作用记录影响对象、业务 ID、确认人、结果和清理状态。
- 验收：高风险误操作为 0，非 E2E 对象修改／删除为 0。

### GAE-GUI-13：多账号角色与会话矩阵

- 项目可配置管理员、普通测试、只读、运维／开发者等账号槽位，只保存密钥引用，不保存明文凭据。
- 支持自动登录保存会话、交互录制、会话过期识别、重新录制、清理和运行级账号切换。
- 权限不足、账号失效和会话过期归类为账号／权限或环境问题，不默认记为产品缺陷。
- 验收：S01／S02／S05 和授权矩阵可重复执行，报告、截图元数据与模型记录明文泄露为 0。

### GAE-GUI-15：完整页面地图与低风险 UI 探测

- 兼容性扫描升级为持久 `app-map.json`，覆盖页面 ID、路由、名称、主区域、菜单、页签、按钮、输入、下拉、上传、表格列、卡片字段、弹窗、Canvas、iframe、Shadow DOM、低稳定定位和高风险动作。
- 扫描分为只读扫描和显式低风险探测；低风险探测只允许菜单／页签切换、打开／关闭弹窗，禁止保存、上传、删除、启动、停止和重启。
- 记录全局导航、局部页签、固定侧栏和页面滚动容器，不把右侧滚动误作用于左侧项目栏。
- 验收：登录后五个主模块和指导书列出的所有二级模块进入页面地图，S03／S04／S11／S30 可由页面地图驱动。

## 4. P1：目标站复杂组件、语义和证据

### GAE-GUI-07：GAEALaViC 业务上下文包

- 使用已具备的结构化上下文模型，交付 GAEALaViC 术语、对象关系、状态机、示例目标、允许／禁止操作、Bridge 能力和语义目标。
- 上下文至少覆盖装备智能体→实例→想定→DoE／运行→数据／评估，以及环境资产／高程→地理空间配置。
- 未获得目标系统确认的业务事实必须标记缺失并阻塞，不得由模型猜测。

### GAE-GUI-09：复杂 Web 组件适配

- 支持级联下拉、虚拟列表、可搜索选择器、日期时间范围、分页、统计卡片、标签页、上传弹窗、图片预览和局部滚动。
- 建立模块适配覆盖：登录、全局导航、装备智能体、环境资产、高程数据、想定、运行、强化学习、帮助。
- 组件适配保持通用语义接口，目标站选择器和规则放在项目适配包中，不污染通用执行器。

### GAE-GUI-10：Canvas 通用视觉手势补齐

- 在已具备点击／悬停／滚动／拖拽基础上，补齐 Canvas 区域缩放、清除和多点绘制动作。
- 多边形至少记录 3 个顶点；矩形记录边界框；每次动作记录 Canvas 边界、相对坐标、固定 viewport、视觉目标和 fallback 原因。
- 无 Bridge 的黑盒视觉步骤稳定性不得标为 A，且不能把探索坐标固化为稳定 locator。

### GAE-GUI-11：目标站 Cesium Adapter／App Bridge

- 在 Bridge v1 五项契约基础上，为 GAEALaViC 建立可替换适配包；不把 Cesium 对象泄露到通用 Agent／Runner。
- 语义状态覆盖图层 ID／名称／可见性、相机经纬高和姿态、实体数量、选中实体、路径点、POI、围栏、多边形、矩形、tilesLoaded 和 WebGL error。
- Bridge 是可选增强，不是开始测试的硬前置；不可用时保留 L0／L1／视觉路线并如实降低稳定性等级。

### GAE-GUI-12：Cesium／Canvas 业务断言与 Finding

- 新增图层、相机、实体、路径点、POI、围栏、绘制对象、瓦片加载和 WebGL 错误断言。
- Finding 在既有七类基础上关联业务对象 ID、场景状态、console／network／WebSocket 和目标站预期。
- 区分产品缺陷、locator 失效、测试数据、账号／权限、环境、时序和 AI 无法判断。

### GAE-GUI-16：标准证据包与完整率计算

- 每次运行按指导书生成或可导出：运行元数据、脱敏项目／环境、兼容性扫描、页面地图、DOM／ARIA、动作时间线、console、失败请求、WebSocket、模型调用、截图、Trace、上传、下载、生成测试、Finding、审核历史、清理报告和验收摘要。
- 所有证据条目使用同一 run ID、step ID 和业务 ID 关联；缺失项必须标记“不适用”或缺失原因，不能静默省略。
- 自动计算证据完整率并在 GUI、JSON、Markdown 和 HTML 中展示。
- 验收：适用证据完整率不低于 95%，明文敏感信息泄露为 0。

## 5. P2：可执行基准与 L4 闭环

### GAE-GUI-14：30 场景基准执行与统计

- 交付指导书 S01～S30 的可执行 YAML／JSON；每个场景绑定环境、账号角色、前置数据、步骤／目标、断言、危险策略、清理和证据要求，不能只保存自然语言。
- 支持同版本、固定数据下每场景重复 5 次，总计至少 150 次运行；记录完成率、stable 成功率、adaptive／视觉介入、证据完整率、清理率和失败分布。
- 输出机器可读 `acceptance-summary.json` 和人工可读验收报告，失败可追溯到 run、step、业务对象和证据。

### GAE-GUI-17：GAEALaViC L4 跨模块业务闭环

- 跑通：登录→上传／创建模型→创建环境资产／高程→创建／导入想定→关联实例→启动仿真→等待运行→停止／完成→运行记录→仿真／评估下载→逆序清理→证据与报告。
- 闭环中所有创建对象有 E2E 前缀和业务 ID，所有上传／下载有 SHA-256，仿真有运行 ID和状态时间线，停止失败有人工处理清单。
- L4 主闭环必须至少完整成功一次，不能用总体 80% 场景完成率掩盖核心链路失败。

## 7. 功能发布与企业实测门槛

`1.30.10` 的功能完成口径已由用户在 2026-07-22 明确调整：公司内网实跑不是功能封装前置条件。只要两份指导书要求的 GUI 能力、目标站适配模板、可执行绑定机制、30×5 批次产品和 L4 编排产品均实现并通过本地／Docker 验证，即可封装 `1.30.10`，但发布说明必须标记“企业目标站未实测”。下表继续作为取得“企业目标站已验证”结论的门槛。

| 指标 | `1.30.10` 门槛 |
| --- | --- |
| 基准场景 | S01～S30 均有可执行 YAML／JSON |
| 重复次数 | 每场景 5 次，至少 150 次 |
| 场景完成率 | >= 80% |
| L4 主闭环 | 至少 1 次完整成功，核心链路不得被总体完成率掩盖 |
| 稳定回放成功率 | >= 95% |
| 证据完整率 | >= 95% |
| 业务对象清理成功率 | 100% |
| 高风险误操作 | 0 |
| 明文敏感信息泄露 | 0 |
| 裸坐标稳定用例 | 0 |
| 未授权域名访问 | 0 |

任一安全零容忍指标不满足，或 L4 主闭环未成功，均不得声明“GAEALaViC 企业目标站已验证”；这不阻止按指导书完成功能封装。

指标计算口径：

- 场景完成率 = 150 次计划运行中 `goal_status=achieved` 的次数 ÷ 150；blocked 仍计入未完成，因此外部依赖未齐时不能靠缩小分母发布。
- 稳定回放成功率 = 所有被标记为 stable 候选的实际回放中成功次数 ÷ stable 回放总次数；不得排除失败重试。
- 证据完整率 = 所有运行中“适用且要求存在”的证据项实际存在并通过结构校验的数量 ÷ 应存在数量；不适用项必须有机器可读理由。
- 清理成功率 = 本轮创建／复制／导入且要求清理的业务对象中，经查询确认不存在的数量 ÷ 应清理对象总数。
- L4 成功与上述比例独立判断；完整链路任一必需步骤失败都不能记为 L4 成功。
