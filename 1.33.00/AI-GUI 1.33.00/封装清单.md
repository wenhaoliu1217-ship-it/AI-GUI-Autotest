# AI-GUI 1.33.00 Windows 组员交付包封装清单

## 交付定位

本包是 1.33.00 的 Windows process Runner 测试交付版，供组员解压后直接启动 GUI 并继续进行真实网站验收。它不是最终业务发布版；Cesium 真实账号、控件定位、资产预览/详情和地图交互闭环由组员在授权环境中继续验证。

## 本轮代码状态

- 只修改和封装 `1.33.00`，不修改、不覆盖 `1.32.00`。
- 开源 GUI-Agent 能力以产品自有适配层接入观察、决策、批准、执行和证据链；不把未经审计的第三方浏览器控制权直接放进产品。
- 修正 Cesium 资产列表判断：具体的“预览/详情”目标不能仅凭资产列表事实提前完成，必须继续进入对应的专用状态机。
- 最新定向 Planner 回归：5 passed；源代码与 Windows 运行包中的 `agent_planner.py` SHA-256 一致。

## 包含内容

- `backend/src`：1.33.00 产品后端和开源适配策略。
- `backend/benchmarks`：Cesium、通用网页和开源适配评测 fixture。
- `dist`：生产前端构建产物。
- `runtime/python`：内置 Python 3.12 及应用依赖。
- `runtime/ms-playwright`：内置 Playwright 浏览器运行时。
- 启动/停止 BAT、PowerShell 脚本和 Windows 使用说明。
- 组员交付说明、开源适配说明、版本状态和验证记录。

## 明确排除

- Docker 镜像和 `.venv`。
- 历史 `artifacts`、历史 `data`、浏览器登录态、Cookie、API Key 和运行日志。
- 后端测试临时目录、测试源码和上游开源仓库原件。

首次启动后，程序会在解压目录中自行创建 `data`、`artifacts` 和运行日志目录；这些目录只保存组员本次测试数据，不应回填到交付 ZIP。

## 交付文件

- 文件：`构建成品/AI-GUI-1.33.00-Windows-交付版.zip`
- 顶层目录：`AI-GUI-1.33.00`
- 启动入口：`双击启动AI测试.bat` 或 `Start-AI-GUI.bat`
- 停止入口：`双击关闭AI测试.bat` 或 `Stop-AI-GUI.bat`
- ZIP 同目录提供 `AI-GUI-1.33.00-Windows-交付版.sha256`，用于交付前完整性校验。

## 交付前检查

- 运行时清单产品版本为 `1.33.00`。
- 交付包内不含 1.32.00 文件。
- 包内前端、后端、内置 Python/Playwright 和启动脚本均存在。
- 交付包不携带个人密钥和登录态。
- 组员需要自行配置 AI 服务并在真实授权网站上完成后续验收。
