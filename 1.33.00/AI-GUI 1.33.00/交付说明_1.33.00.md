# AI-GUI 1.33.00 组员交付说明

## 交付定位

这是 1.33.00 Windows process Runner 测试交付包，组员解压后即可启动 GUI 并进行后续真实网站验收。它不是最终业务发布版：Cesium 的真实登录、页面控件定位、资产预览/详情和地图交互闭环由组员在授权账号和测试数据下继续验证。

1.33.00 的代码层已经接入产品自有的开源 GUI-Agent 适配层，包括 Stagehand、Browser-use、UI-TARS、Playwright CLI、OpenAdapt，以及 BrowserGym、AgentLab、WebArena 等评测/轨迹策略。第三方项目不会直接获得绕过产品安全门禁的浏览器控制权；运行仍统一经过产品的观察、决策、批准、执行和证据链。

## 启动

1. 完整解压 ZIP，不要只复制某一个 BAT 文件。
2. 双击 `双击启动AI测试.bat`；如果中文文件名显示异常，双击 `Start-AI-GUI.bat`。
3. 启动器会自动选择 8080～8090 中的空闲端口，并打开本地 GUI。若同机还运行 1.32.00，1.33.00 通常会使用 8081。
4. 顶部显示“真实执行服务已连接”后再开始测试。

本包使用内置 Python、Playwright 和 Chromium，不要求 Docker Desktop，也不会联网执行 pip 安装、Playwright 安装或 Docker 构建。启动窗口需要保持打开。

## AI 与登录

交付包不包含任何 API Key、登录 Cookie 或个人浏览器配置。组员首次使用时：

1. 打开“高级设置 → 更换 AI 服务”。
2. 填写协议、Base URL、模型和组员自己的 API Key。
3. 运行“模型能力探针”；连接、结构化输出和多轮上下文均通过后，再启动逐步 Agent。
4. 打开目标网站后由组员本人完成登录，并在 GUI 中确认“我已登录”。密码、验证码和生物识别不由 AI 代填。

## 建议验收顺序

1. 先运行通用网页回归入口，确认本机服务、浏览器和证据目录正常。
2. 再运行 1.32.00 已通过的 30 条闭环任务，对比 1.33.00 的结果和报告。
3. 最后进行 Cesium 专项：资产列表、资产预览/详情、路由切换、地图定位、测量/绘制等任务。每项都要确认实际页面状态、截图/报告证据和没有提前完成。
4. 在“开源运行时策略”中逐项选择策略时，记录策略名、决策次数、拦截次数、步骤数和证据文件；不要把“仓库已下载”当作上游运行时已验证。

## 停止与问题反馈

- 正常退出：双击 `双击关闭AI测试.bat` 或 `Stop-AI-GUI.bat`。
- 运行结果和截图会生成在解压目录的 `artifacts` 中；这些目录属于组员本次测试数据，不要回填到交付 ZIP。
- 启动失败时先确认没有其他 1.33.00 进程占用端口，再查看 `server-stderr.log`。
- 反馈问题时请一并提供：任务描述、运行编号、报告/截图路径、浏览器页面 URL 和 GUI 中的错误提示；不要提交 API Key、Cookie、密码或验证码。

## 本包边界

- 包含：生产前端、1.33.00 后端、开源适配策略、Cesium 相关能力、内置 Python/Playwright/Chromium、启动/停止脚本。
- 不包含：Docker 镜像、源码仓库、上游开源仓库原件、历史 artifacts、历史 data、登录态和密钥。
- 1.32.00 是独立基线，本次交付包不会覆盖或修改它。
