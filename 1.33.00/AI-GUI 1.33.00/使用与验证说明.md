## 普通用户怎么用

1. 启动后只看左侧“开始测试”。
2. 输入你有权测试的网站地址，点击“开始”。
3. AI 会先安全查看页面，不点击、不填写、不提交。
4. 如果网站需要登录，会弹出登录窗口。你正常登录，再回到 GUI 点击“我已登录”；系统判断成功后继续。
5. 选择“告诉 AI 你想测试什么”，或“让 AI 全面检查这个网站”。全面检查会先列出范围，得到确认才开始。
6. 运行时左侧看网站画面，右侧看 AI 说明和批准请求。
7. 结果先显示普通中文结论；需要时展开“查看技术详情”。

## 三档批准方式

- 请求批准（默认）：填写、选择、勾选、上传等写入动作逐次询问。
- 替我审批：同类低风险动作自动批准，高风险动作逐次询问。
- 完全访问权限：确认后自动批准允许范围内动作，并持续显示警告。

三档都不能绕过绝对安全规则。AI 不会代输密码、验证码或生物识别，不会修改账号安全设置，不会删除非测试数据，也不会实际付款。支付步骤只允许用户本人接管；本项目验收不进行真实付款。

## AI 服务

默认显示内置 AI 入口。算力不可用时，页面提示“内置AI算力有限，请在高级设置中更换AI服务”。点击“更换AI服务”可直达 API 地址、模型与 Key 设置，完成后返回刚才的测试。

Key 仅用于当前会话，不写入浏览器存储、运行历史或报告；刷新页面后清除。

## 高级设置

旧版的项目、环境、场景、固定计划、登录态导入、报告、证据、回放和完整电商验收均保留在高级设置。普通用户无需理解这些技术概念。

京东完整验收仍执行全部 65 项，但普通页面只按登录、商品查找、购物车、提交订单前流程、付款安全、恢复清理、隐私安全等内容显示，不显示 J01～J65。

## Windows 启动

1. 完整解压交付 ZIP，不要只复制某一个 BAT 文件。
2. 本 1.33.00 Windows 交付包默认使用包内 process Runner，不要求 Docker Desktop。
3. 双击 `Windows一键运行/双击启动AI测试.bat`；交付 ZIP 解压后，启动 BAT 位于包顶层。
4. 浏览器打开启动器提示的本地地址；默认从 8080～8090 选择空闲端口。
5. 退出时双击 `双击关闭AI测试.bat` 或 `Stop-AI-GUI.bat`。

当前 1.33.00 候选包使用独立的 process Runner，已重新生成并通过干净归档内容检查；不携带旧版 Docker Runner 镜像。真实 Cesium 授权账号、权威测试数据包和地图交互闭环仍需专项验收后，才能把候选包标记为最终业务发布版。
