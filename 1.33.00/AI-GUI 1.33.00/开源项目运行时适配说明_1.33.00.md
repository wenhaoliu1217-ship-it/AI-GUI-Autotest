# 1.33.00 开源 GUI-Agent 运行时适配说明

## 接入结论

1.33.00 已把开源项目的关键能力接入产品自己的 Agent 运行链。接入的不是未经审计的第三方浏览器控制权，而是产品侧适配策略：

```text
页面 Observation
  -> 开源策略上下文与提示规则
  -> AgentDecision 适配/拦截
  -> 产品决策门禁
  -> 现有安全 Runner
  -> Step/报告/运行证据
```

因此，第三方项目不能绕过域名策略、模型数据授权、业务禁止规则、风险确认和安全执行器。

## 已接入 GUI 的运行时策略

| 项目 | GUI 内的适配策略 | 实际生效位置 |
| --- | --- | --- |
| Stagehand | 从当前 DOM/ARIA 事实生成候选动作；动作必须绑定当前观察到的定位器 | Planner 上下文、决策适配器、运行证据 |
| Browser-use | 注入目标/URL/最近轨迹；限制每轮只产生一个下一动作；敏感状态不进入上下文 | Planner 上下文、决策适配器 |
| UI-TARS | 视觉候选仅在截图授权和视觉 fallback 启用时允许；保留产品视觉动作边界 | Planner 规则、决策适配器、视觉执行链 |
| Playwright CLI | 只使用轨迹事实和命令分类；禁止重放外部 CLI；输入值/Token/Cookie 脱敏 | Planner 上下文、运行证据 |
| OpenAdapt | 为动作链写入检查点；恢复前重新观察页面并重新校验写入动作 | Runner 检查点、恢复链、运行证据 |

Playwright MCP 仍是只读观察适配器；BrowserGym、AgentLab、WebArena 主要进入任务/轨迹/评测证据层，不替代产品 Runner。OSWorld 暂不进入默认 Web 执行链；TestZeus Hercules 因 AGPL-3.0 许可证门禁不作为产品依赖。

## GUI 使用方式

在“传统测试编辑器”中选择“逐步 Agent 探索”，然后在“Agent 开源运行时策略”中选择策略。选择后，请求会携带 `openSourceExecutionProvider`；运行详情和报告会显示策略、决策次数、拦截次数、步骤数、检查点数以及 `evaluations/open-source-execution.json`。

固定计划执行默认使用原生安全 Runner，不会假称第三方策略参与固定计划动作。
