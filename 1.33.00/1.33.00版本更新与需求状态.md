# 1.33.00 版本更新与需求状态

更新时间：2026-08-05

## 本轮目标

1. 保持 `1.32.00` 冻结，只在 `1.33.00` 内继续开发。
2. 将通用网页观察、定位、执行和验证能力与 Cesium 专项适配解耦。
3. 把优秀开源 GUI Agent 项目的可迁移方法吸收到本项目的通用层，而不是直接复制整套工程。
4. 建立至少两个不依赖 Cesium 的本地网页验证基线，作为后续兼容性回归入口。

## 参考项目的首批吸收方向

- Playwright MCP：优先使用可解释的页面观察和语义定位。
- Stagehand：保留“语义动作 + 可验证回退”的执行思想。
- OpenAdapt：将动作、观察和恢复信息作为可回放证据的一部分。
- BrowserGym / AgentLab / WebArena / OSWorld：用任务、环境、观察、动作、结果组成可复现基线。
- TestZeus：只参考测试编排思路；其 AGPL 许可代码不直接并入产品。
