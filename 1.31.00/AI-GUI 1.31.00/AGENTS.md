# AI-GUI 1.31.00 开发规则

本目录是 `1.31.00` Agent-first 通用母版的唯一产品工作区。

- 直接代码基线是冻结的 `1.30.31`；不得回写 `1.30.31`、`1.30.30`、`1.30.10` 或 `1.30.00`。
- 默认入口必须是自然语言业务目标和逐步 Agent；固定计划只用于调试、稳定回放和 CI，不能计为 Agent 验收通过。
- 京东、GAEALaViC、Cesium 等站点常量、选择器和路由必须留在领域 profile、Adapter 或 benchmark，不能进入通用执行核心。
- 澄清、人工确认和风控接管必须暂停同一 run，保留浏览器、登录态、页面和轨迹；不得重放已经成功的副作用动作。
- 模型接收 DOM 或截图必须逐网站显式授权。密钥、Cookie、验证码、设备标识、个人资料和交易标识不得进入明文证据。
- 电商真实支付永远禁止。正式站提交未支付订单必须同时具备专用账号、固定测试商品和地址、书面授权、自动取消清理。
- 每批修改必须有相应测试，并同步源码、Windows 一键运行、构建成品、版本状态和根接续说明。
- 发布前必须重建独立 Runner，完成干净解压、离线双击、端口释放和 SHA-256 验收。
