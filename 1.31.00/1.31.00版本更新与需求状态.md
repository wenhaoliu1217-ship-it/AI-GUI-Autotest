## 版本定位

`1.31.00` 是新的 Agent-first 跨网站通用母版，同时承接 `1.30.31` 已验证的安全、电商基础设施和离线交付能力。它不以固定计划通过冒充 Agent 验收，也不把京东、GAEALaViC 或 Cesium 的站点常量写入通用核心。

## 必须完成

- 默认自然语言业务目标直接启动逐步 Agent，固定计划仅用于调试、stable 回放和 CI。
- Agent 信息不足时最多澄清 3 轮，并在同一 run、浏览器、登录态、页面和轨迹中恢复。
- 区分 `agent_passed`、`fixed_passed` 和 `fallback_passed`，Agent 门禁与业务结果门禁同时通过。
- 通过真实探针确认模型 ID、协议、Schema、多轮和视觉能力，不根据名称猜测。
- DOM／截图传模采用逐网站授权；企业内网页面必须单独得到企业负责人批准。
- 保留电商支付前绝对边界、正式站四项授权条件、幂等、证据和自动清理能力。
- 合并 `1.30.10` 中当前缺失的站点无关验收、文件、异步、生命周期、复杂组件、30x5 和 L4 能力。
- 完整同步源码、Windows 一键运行、构建成品和独立 Docker Runner，完成干净解压离线双击验收。

## 最终实现与验证

- 默认逐步 Agent 直接接收自然语言目标；固定计划保留为调试、stable 回放和 CI，执行来源明确区分为 `agent_*`、`fixed_*`、`fallback_passed` 和 `unverified`。
- 最多三轮结构化澄清在同一 run、浏览器、页面、登录态和轨迹中恢复；危险动作确认保持独立门禁。
