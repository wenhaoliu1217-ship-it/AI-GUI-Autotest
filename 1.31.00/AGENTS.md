# 1.31.00 AI 开发强制规则

本文件适用于 `1.31.00` 及全部子目录。

1. 本版本从冻结的 `1.30.31` 完整复制建立，是新的 Agent-first 通用母版；只允许修改 `1.31.00`。
2. 从 `1.30.10` 迁移能力时，只迁移站点无关实现；GAEALaViC 和 Cesium 专用常量必须隔离为 profile 或 Adapter。
3. `1.30.31` 的固定执行、账号态和基础安全能力可作为迁移基础，但不能作为 Agent-first 验收证据。
4. 任何真实站写操作都必须同时满足领域边界、逐站授权、人工门禁、幂等和清理要求；绝不执行真实支付。
5. 不得记录用户在聊天中提供的账号、密码或 API 密钥；只使用临时人工输入或环境密钥引用。
6. 更新代码时同步 `1.31.00版本更新与需求状态.md` 和根接续说明，未经完整回归不得标记完成或冻结。
