# AI-GUI 1.20.00 功能说明

> 版本来源：用户指定的原始 `MATC-8.17_AIGU-2.3_AI接入V.2.zip`。
> 定位：V2 历史基线，只读保留，不作为当前继续开发版本。
> 完整版本目录：`AI-GUI 1.20.00`。

## 1. 产品形态

- React／Vite Web 管理端。
- FastAPI 本地执行服务。
- Playwright Chromium 真实浏览器执行。
- Windows 一键运行包、源码、静态构建、验证输出和真实联调截图。
- 页面包括总览、AI 模型设置、新建测试、执行详情、历史报告和报告详情。

## 2. 测试计划生成

### 2.1 规则规划

- 用户填写目标 URL、用例名称、执行角色、前置条件、自然语言业务流程和预期结果。
- 规则规划器按分号／换行拆分“输入、点击、等待、截图、确认看到”等明确操作语句。
- 无法识别的步骤会返回警告，不能进入审核和执行。
- 规则规划阶段不打开目标页面，也不读取 DOM。

### 2.2 AI 一次性规划

- 支持 OpenAI Responses API 和兼容 Chat Completions。
- API Key 仅保留在当前页面内存并随请求进入本机后端，不落盘。
- 名称、URL、流程、角色、前置条件和预期结果会进入 AI Prompt。
- AI 一次性返回完整固定 `TestPlan`，再经过 Pydantic Schema、动作白名单和目标 URL 校验。
- AI 不读取实时 DOM／Accessibility，也没有逐步 Observation→决策循环。
- 角色和前置条件可能影响 AI 计划，但尚未形成强制执行策略；代码中没有“默认客户视角”。

## 3. 审核与真实执行

- 计划生成后必须人工审核并校验，之后才能运行。
- 支持固定 Playwright 动作和断言，最终成功／失败来自真实浏览器，不由前端 Mock 生成。
- 未连接执行服务时明确报错并禁止运行。
- 默认拒绝目标页面跨域跳转。
- 无法解析的自然语言不会伪造成成功结果。

## 4. 证据与报告

- 每个已执行步骤保存真实 PNG 截图。
- 每次运行保存 `run.json`、`events.jsonl`、HTML／Markdown 报告、Playwright Trace 和截图目录。
- 报告展示步骤状态、失败步骤、断言、错误类别、复现步骤和截图入口。
- 历史报告读取真实后端运行记录。
- 已验证真实成功路径和定位失败路径。

## 5. 1.20.00 不具备的能力

- 没有项目／环境／场景库完整持久化管理。
- 没有 L0～L3 深度兼容性扫描和自动示例场景。
- 没有后台 Run Orchestrator、轮询、取消和异常恢复。
- 没有逐步 DOM Agent、视觉适配器、Canvas 相对坐标或 App Bridge。
- 没有动作前后完整 Observation、结构化 Finding 和人工问题审核。
- 没有 A～D 稳定性、审核路径、生成源码修订和真实自适应回放。
- 不支持顶层业务目标自主拆解；用户仍需填写较明确的操作流程。
- 不具备完整 Cesium、Computer Use、垂直业务上下文或企业安全闭环。
